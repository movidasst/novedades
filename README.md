# Novedades ISO SST · La Movida de SST+

Radar público de normas y proyectos ISO relevantes para seguridad y salud en el trabajo.

## Incluye
Gestión SST, higiene ocupacional, ergonomía, señalización y emergencias. El sitio consulta RSS oficiales de ISO.org cada 6 horas mediante GitHub Actions.

## Cómo agregar otra norma
Busca la norma en ISO.org y copia la URL de su ficha. El sitio incluye un generador visual de RSS. Para incorporarla al radar, añade una entrada en `data/feeds.json` con `standard_id`, `reference`, `topic`, `category` y `page`.
