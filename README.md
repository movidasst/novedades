# Novedades ISO SST · La Movida de SST+

Radar público para seguir normas y proyectos de seguridad y salud en el trabajo vinculados al **ISO/TC 283**.

## Qué hace

- Consulta RSS oficiales de ISO.org.
- Muestra número, tema, etapa y fecha del último cambio.
- Permite buscar y filtrar por estado.
- Actualiza los datos automáticamente cada 6 horas mediante GitHub Actions.
- Mantiene siempre un enlace hacia la ficha oficial de ISO.

## Sitio

https://novedades.movidasst.com

## Fuentes vigiladas

ISO/DIS 45001, ISO 45002, ISO 45003, ISO 45004, ISO/PAS 45005, ISO 45006, ISO/PAS 45007, ISO/DIS 45008, ISO/AWI 45009 e ISO 45010.

Para agregar otra norma, basta con añadir su RSS oficial a `data/feeds.json`.

> Proyecto independiente de La Movida de SST+. ISO es una organización externa; esta web resume metadatos públicos y remite a ISO.org como fuente original.
