Glosario ISO

¿Qué significa 50.00? ¿Qué diferencia hay entre DIS y PAS? Consulta aquí los códigos y las siglas.

Cómo leer 50.00

50 identifica la etapa de aprobación y .00 su registro inicial. El texto final se ha recibido o el FDIS se ha registrado para aprobación formal.

Aún no significa «publicado». El código expresa un estado del proceso, no un porcentaje de avance ni una fecha de publicación.

Siglas de proyectos y borradores: AWI, WD, CD, DIS y FDIS
NP / NWIPNew Work Item Proposal
Propuesta de nuevo trabajo. Se plantea desarrollar un documento.
AWIApproved Work Item
Trabajo aprobado. El proyecto entra al programa de desarrollo.
WDWorking Draft
Borrador de trabajo. Los expertos preparan el texto.
CDCommittee Draft
Borrador de comité. Se consulta dentro del comité para construir consenso.
DISDraft International Standard
Proyecto de Norma Internacional. Se somete a consulta y votación de los miembros de ISO.
FDISFinal Draft International Standard
Proyecto final de Norma Internacional. Se presenta para aprobación final; todavía no es la publicación definitiva.

El recorrido puede omitir determinadas etapas según el procedimiento aplicable. Directivas ISO/IEC ↗

Tipos de documentos: IS, PAS, TS, TR e IWA
ISInternational Standard
Norma Internacional. Puede establecer requisitos, métodos o directrices.
PASPublicly Available Specification
Especificación disponible públicamente. Responde a necesidades urgentes y se publica para uso inmediato; puede evolucionar a Norma Internacional.
TSTechnical Specification
Especificación técnica. Se utiliza cuando el desarrollo técnico o el consenso aún no permiten una Norma Internacional.
TRTechnical Report
Informe técnico. Presenta información, datos o el estado del conocimiento sobre un tema.
IWAInternational Workshop Agreement
Acuerdo de taller internacional. Se desarrolla mediante talleres con las partes interesadas.

PAS es un tipo de documento, no una etapa. Una referencia con PAS también puede llevar un prefijo de proyecto. Comprueba el código y la ficha para saber si está publicado.
